# Assignment 1: Problem Solving with TypeScript & OOP

## Overview

This repository contains my solutions for **Module 4 – Assignment 1**, focusing on Problem Solving with TypeScript and Object-Oriented Programming (OOP).

The assignment demonstrates my practical understanding of core TypeScript concepts, including basic types, optional parameters, union types, readonly tuples, interfaces, generics, type narrowing, asynchronous programming, and OOP principles.

## Technologies Used

- TypeScript
- Object-Oriented Programming (OOP)
- JavaScript ES6+
- TypeScript Generics
- Promises and Async/Await

## Assignment Solutions

All eight coding problems are implemented in a single TypeScript file:

- `B8A1.ts`

The solutions cover:

1. Optional and default parameters
2. Union types and type narrowing
3. Readonly tuples
4. Generic functions and rest parameters
5. Interfaces and array filtering
6. Generics with `keyof` constraints
7. Classes, inheritance, and access modifiers
8. Asynchronous programming with Promises

## Blog Posts
